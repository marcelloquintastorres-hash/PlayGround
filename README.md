## 🛡️ Guardião da Arena

Jogo de ação 3D feito para celular e tablet. Enfrente hordas de criaturas na arena, ganhe XP a cada abate e suba até o **nível 100** para vencer.

- **Celular/tablet:** analógico virtual para mover e botão **ATACAR** (segure para atacar continuamente).
- **Computador:** `WASD`/setas para mover e `Espaço` para atacar.
- Ataque em área ao redor do herói, números de dano, partículas, som sintetizado e indicadores para inimigos fora da tela.
- Três tipos de criaturas, ondas progressivas, cura ao subir de nível e tela de vitória no nível 100.

Tecnologia: HTML/CSS/JS + Three.js (biblioteca local em `vendor/`), sem etapa de build.
